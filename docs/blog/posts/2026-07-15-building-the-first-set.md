# Building the First Set

The first set needs a clean arc: a bright opener, a dancer-friendly medium swing chart, a feature that lets the room settle, and a closer with enough lift to make the break feel earned.

The current draft starts with a compact ensemble chart and leaves the longer solo space until the second tune. That keeps the first downbeat clear and gives the audience a reason to lean in before the band stretches.

## Working Order

1. Opener with a crisp brass answer.
2. Medium swing with sax section focus.
3. Vocal feature.
4. Blues chart with rhythm section trading.
5. Shout chorus closer.
